# 体育比赛主客队英文名相似度（易语言示例）

已修正为可直接参考的易语言代码示例：
- 输入主队英文名
- 输入客队英文名
- 点击计算得到相似度分值（0~100，100 最高）

## 规则说明
示例采用“同位置字符匹配”来做基础相似度计算：
1. 比较两个英文名在相同位置上的字符是否一致
2. 统计一致字符数
3. 使用公式换算为 0~100 分

公式：
`相似度 = (同位置相同字符数 × 200) ÷ (主队名长度 + 客队名长度)`
